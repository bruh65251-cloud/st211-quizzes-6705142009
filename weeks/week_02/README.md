# Week 02 - Writing Effective Test Cases

This week I focused more on how test cases should be designed and organized instead of only checking whether the code passes or fails.

## What I Practiced

- Writing clearer and more independent test cases
- Using the Arrange-Act-Assert (AAA) idea
- Testing different input conditions
- Comparing dependent and independent tests
- Testing expected behavior using pytest
- Organizing related test cases

## In-Class Work

The class exercises included testing simple program logic such as:

- Bank account operations
- Grade calculations
- Tests that share the same state
- Tests that create their own independent state

One important thing I learned was that tests should usually be independent so that one test does not affect the result of another test.
