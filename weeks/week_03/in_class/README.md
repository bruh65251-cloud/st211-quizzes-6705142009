# Week 03 - Assertions and Test Organization

This week I practiced writing different types of assertions and organizing test cases using pytest.

## What I Practiced

- Testing collections and floating-point values
- Writing positive and negative test cases
- Testing validation functions with different inputs
- Testing the behavior of a simple class
- Organizing related tests into separate test files

## In-Class Work

The exercises included:

- Collection and floating-point assertion examples
- Validation testing with positive and negative cases
- Shopping cart function and class testing

## What I Learned

I learned that tests should check different possible behaviors, not only the expected successful case. Separating related tests also makes the test suite easier to understand and maintain.
